# Перечень требований и выбранных пакетов

| № | Функциональное требование | Выбранный пакет | Назначение |
|---|---|---|---|
| 1 | Хранение данных в БД | illuminate/database | Query Builder + Eloquent ORM |
| 2 | Кеш в памяти для сложных запросов | orieg/judy-cache | Высокопроизводительный in-memory кеш (PSR-6/PSR-16) |
| 3 | Формирование XLS-отчётов | phpoffice/phpspreadsheet | Генерация Excel-файлов |
| 4 | Формирование PDF-документов | barryvdh/laravel-dompdf | Быстрая генерация PDF из HTML |
| 5 | Отправка SMS для верификации | tecdiary/sms | Поддержка Twilio, Nexmo, Infobip и др. |
| 6 | E-mail-уведомления и рассылки | mailersend/mailersend | Официальный SDK для транзакционных писем |
| 7 | Облачное хранилище (AWS S3 / Azure Blob) | aws/aws-sdk-php | Официальный SDK Amazon S3 |
| 8 | Интеграция со службой доставки | lapaygroup/russianpost | API Почты России (тарифы, отслеживание) |
| 9 | Авторизация через соцсети | hybridauth/hybridauth | Единый API для Facebook, Google, VK и др. |
| 10 | Отправка данных в Яндекс.Маркет | yandex-market/php-partner-api | Работа с Partner API / YML-фидами |
| 11 | Приём онлайн-оплаты | balerka/laravel-payhub | Абстракция платёжных шлюзов |
| 12 | Средства тестирования | phpunit/phpunit | Модульное тестирование |
